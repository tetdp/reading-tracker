# 📚 Reading Tracker App

A simple and clean web application to help you keep track of your reading progress!  
Add books you're currently reading, track your progress with a visual progress bar, and export your reading list to a CSV file.

## ✨ Features

- ✅ Add books with title, author (optional), total pages, and pages read
- 📊 Live progress bar for each book
- 🌙 Dark mode toggle
- 🖼️ Add cover image to personalize your reading list
- 📤 Export your book list to a `.csv` file
- 🗑️ Remove books from the list
- 🔁 All data is saved in your browser (localStorage)

## 💡 Tech Stack

- **HTML**
- **CSS**
- **JavaScript (Vanilla)**

No frameworks or libraries used – built from scratch!
